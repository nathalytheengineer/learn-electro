Schematic Symbol Finder

Describe a mark on an electrical drawing and get representative symbol sketches, notations, and usage guidance — all in your browser.

Made for learning how PLCs, MCCs, and field circuits fit together · Browser-only demo
Open the live demo (local build)

Why this helps

Quickly identify common schematic marks and instructional ladder symbols (XIC/XIO, OTE) using simple natural-language descriptions. The app ranks likely matches and shows representative SVG sketches and notations for teaching and troubleshooting.

How to use

Type a short description into the box (for example: ladder XIO slash contact) and choose a drawing context if you know it (control, power, ladder, instrument). The app returns a ranked match and alternatives with notes about distinctions.

Technical notes

The project is client-side only and builds a single-file snapshot at docs/index.html. It's ready to host on GitHub Pages, Netlify, or Vercel. Source files are modular (ES modules) and the build script inlines CSS/JS into the snapshot.

Try it

npm run build
npx http-server docs -p 5000
# open http://localhost:5000
